- 更新结构：单调双端队列
  - 从尾巴进队列
  - 进队列的数比尾巴大或相等，尾巴的数开始弹出，弹到空或者尾巴的数比进队列的数大  
  - 进队列的时候要看窗口的大小，R-L+1 > W，要将R-W的数淘汰.(W是窗口的大小)
  - 窗口头部的数就是此时的最大值

- 实践复杂度：O(N) -> 平均到单次O(1)
