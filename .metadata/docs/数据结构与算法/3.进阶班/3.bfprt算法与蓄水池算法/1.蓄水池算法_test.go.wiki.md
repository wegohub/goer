## 问答



**问：golang用蓄水池算法实现全球登录用户抽100个幸运观众**

答：蓄水池抽样算法（Reservoir Sampling）是一种用于从大数据集中随机抽取样本的算法。它的优点在于不需要事先知道数据集的大小，并且可以在一次遍历中完成抽样。下面是一个使用Go语言实现蓄水池抽样算法来从全球登录用户中抽取100个幸运观众的示例代码：

```go
package main

import (
	"fmt"
	"math/rand"
	"time"
)

// ReservoirSampling 使用蓄水池抽样算法从全球登录用户中抽取100个幸运观众
func ReservoirSampling(users chan string, k int) []string {
	rand.Seed(time.Now().UnixNano())

	// 初始化蓄水池
	reservoir := make([]string, k)
	i := 0

	// 遍历用户通道
	for user := range users {
		if i < k {
			// 填充蓄水池的前k个元素
			reservoir[i] = user
		} else {
			// 以k/i的概率替换蓄水池中的元素
			j := rand.Intn(i + 1)
			if j < k {
				reservoir[j] = user
			}
		}
		i++
	}

	return reservoir
}

func main() {
	// 模拟全球登录用户通道
	users := make(chan string)

	go func() {
		for i := 1; i <= 1000000; i++ {
			users <- fmt.Sprintf("user%d", i)
		}
		close(users)
	}()

	// 抽取100个幸运观众
	luckyUsers := ReservoirSampling(users, 100)

	fmt.Println("幸运观众名单：")
	for _, user := range luckyUsers {
		fmt.Println(user)
	}
}
```

#### 代码解释
1. **ReservoirSampling函数**：
   - 接受一个用户通道`users`和一个整数`k`，表示要抽取的幸运观众数量。
   - 初始化一个大小为`k`的蓄水池`reservoir`。
   - 遍历用户通道，对于前`k`个用户，直接放入蓄水池。
   - 对于第`k+1`个及之后的用户，以`k/i`的概率替换蓄水池中的元素。

2. **main函数**：
   - 模拟一个包含100万个用户的通道。
   - 调用`ReservoirSampling`函数抽取100个幸运观众，并打印结果。

这个算法保证了每个用户被抽中的概率是相等的，即使数据集的大小是未知的。
