- 删除策略
```
1. 无左无右直接替换
2. 有左无右或有右无左，用左或右孩子替换
3. 有左有右，再后继节点，x的右树上的最左
```

- 平衡性调整
```
LL LR RR RL

LL: 做一次右旋
LR: 孙子来到头,孩子左旋，父右旋
RR: 做一次左旋
RL: 孙子来到头,孩子右旋，父左旋
LL和LR/RR和RL: 按照LL调整
```
