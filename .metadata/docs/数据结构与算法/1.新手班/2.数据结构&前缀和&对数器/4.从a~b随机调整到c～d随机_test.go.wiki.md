## 总结

#### 思路
- 将f()函数改造成0、1发生器
- 利用二进制位，[1-7] == [0,6]+1, 需要3个二进制位，设计一个函数等概率返回000 ~ 111，产生[0,7]的等概率函数。
- 将[0,7]等概率函数改造成[0,6]函数
- 最后将[0,6]函数+1的到[1,7]等概率发生器。

#### 推广
- 给定一个a~b上等概率的函数，改造成01发生器
- 由c~d决定用多少个二进制位，d-c => 推出二进制位
- 生成[0~d-c]的等概率发生器，产生的结果再+c。
- eg: c=17,d=56, d-c=39用6个二进制位，产生[0,63]等概率随机，>39重做，产生[0,39]等概率随机，[0,39]+17就是[17,56]等概率随机。

## 问答



**问：golang goto语法的用法**

答：在Go语言中，`goto`语句用于无条件地转移到程序中指定的标签处。`goto`语句通常用于简化复杂的控制流程，但过度使用会导致代码难以理解和维护，因此应谨慎使用。

以下是`goto`语句的基本用法：

1. **定义标签**：标签是一个标识符，后面跟着一个冒号（:）。
2. **使用goto语句**：`goto`关键字后面跟着标签名。

下面是一个简单的示例，展示了如何使用`goto`语句：

```go
package main

import "fmt"

func main() {
    var i int

loop:
    if i < 5 {
        fmt.Println(i)
        i++
        goto loop
    }

    fmt.Println("循环结束")
}
```

在这个示例中，`loop`是一个标签，`goto loop`语句会无条件地跳转到`loop`标签处，从而实现了一个简单的循环。

#### 注意事项

1. **避免跳过变量初始化**：使用`goto`语句时，应避免跳过变量初始化，否则会导致编译错误。
2. **避免跳入新的作用域**：`goto`语句不能跳入新的作用域（例如，不能跳入一个函数或一个`if`语句块内部）。
3. **避免形成死循环**：确保`goto`语句不会导致死循环。

#### 示例：避免跳过变量初始化

```go
package main

import "fmt"

func main() {
    var i int

    goto loop
    j := 10 // 这行代码会被跳过，导致编译错误

loop:
    if i < 5 {
        fmt.Println(i)
        i++
        goto loop
    }

    fmt.Println("循环结束")
}
```

在这个示例中，`goto loop`语句跳过了变量`j`的初始化，会导致编译错误。

#### 示例：避免跳入新的作用域

```go
package main

import "fmt"

func main() {
    var i int

    if i < 5 {
        goto loop // 这会导致编译错误，因为跳入了新的作用域
    }

loop:
    fmt.Println(i)
    i++
    if i < 5 {
        goto loop
    }

    fmt.Println("循环结束")
}
```

在这个示例中，`goto loop`语句试图跳入`if`语句块内部，会导致编译错误。

总之，`goto`语句在Go语言中是一个强大的工具，但应谨慎使用，以避免代码变得难以理解和维护。
