## 总结

- bit map可以做集合
- bit map 可以极大的压缩空间
- 实现：用一个bit map 来表示 0-1024 的数有没有出现过，bit map用int64实现
  ```
  容器长度：(max + 64) / 64
  在第几个数：val / 64 == val >> 6
  在第几位: val % 64 == val & 63
  add: arr[num >> 6] |= 1 << (num & 63)
  delete: arr[num >> 6] &= ^(1 << (num & 63))
  find: arr[num >> 6] & (1 << (num & 63)) != 0
  ```
