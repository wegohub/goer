## 总结

在Go语言中，位运算符用于对整数在内存中的二进制位进行操作。以下是Go语言中支持的位运算符：

1. **按位与（&）**：
   - 对两个数的每一位执行与操作。如果两个相应的二进制位都为1，则结果为1，否则为0。
   ```go
   a := 60 // 二进制为 0011 1100
   b := 13 // 二进制为 0000 1101
   result := a & b // 结果为 0000 1100，即 12
   ```

2. **按位或（|）**：
   - 对两个数的每一位执行或操作。如果两个相应的二进制位有一个为1，则结果为1，否则为0。
   ```go
   a := 60 // 二进制为 0011 1100
   b := 13 // 二进制为 0000 1101
   result := a | b // 结果为 0011 1101，即 61
   ```

3. **按位异或（^）**：
   - 对两个数的每一位执行异或操作。如果两个相应的二进制位不同，则结果为1，否则为0。
   ```go
   a := 60 // 二进制为 0011 1100
   b := 13 // 二进制为 0000 1101
   result := a ^ b // 结果为 0011 0001，即 49
   ```

4. **按位取反（^）**：
   - 对一个数的每一位执行取反操作。如果相应的二进制位为0，则结果为1，否则为0。注意，取反操作在Go中也可以用作一元运算符。
   ```go
   a := 60 // 二进制为 0011 1100
   result := ^a // 结果为 1100 0011，即 -61（注意这里是补码表示）
   ```

5. **左移（<<）**：
   - 将一个数的所有二进制位向左移动指定的位数，右边用0填充。
   ```go
   a := 60 // 二进制为 0011 1100
   result := a << 2 // 结果为 1111 0000，即 240
   ```

6. **右移（>>）**：
   - 将一个数的所有二进制位向右移动指定的位数，左边用符号位填充（对于无符号数用0填充）。
   ```go
   a := 60 // 二进制为 0011 1100
   result := a >> 2 // 结果为 0000 1111，即 15
   ```

- 异或运算 == 无进位相加
- a + b == (a ^ b)[无进位相加] + ((a & b) << 1)[进位信息] => 一直递归到进位信息消失
- golang带不带符号移动是由数据类型决定的，eg: int就是带符号，uint就是不带符号
