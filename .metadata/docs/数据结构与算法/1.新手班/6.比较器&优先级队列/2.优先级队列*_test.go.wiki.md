**问：golang "container/heap" 如何实现小根堆？**

答：在 Go 语言中，`container/heap` 包提供了一个堆的接口，你可以通过实现这个接口来创建不同类型的堆，包括小根堆（最小堆）。下面是一个如何实现小根堆的示例：

1. 首先，你需要定义一个类型来表示堆中的元素。这个类型需要实现 `heap.Interface` 接口。

2. 然后，你需要实现 `heap.Interface` 接口中的方法：`Len`、`Less`、`Swap`、`Push` 和 `Pop`。

下面是一个完整的示例代码，展示了如何实现一个小根堆：

```go
package main

import (
	"container/heap"
	"fmt"
)

// IntHeap 是一个整数的最小堆。
type IntHeap []int

// Len 返回堆的长度。
func (h IntHeap) Len() int { return len(h) }

// Less 比较两个元素的大小，用于决定堆的顺序。
func (h IntHeap) Less(i, j int) bool { return h[i] < h[j] }

// Swap 交换两个元素的位置。
func (h IntHeap) Swap(i, j int) { h[i], h[j] = h[j], h[i] }

// Push 向堆中添加一个元素。
func (h *IntHeap) Push(x interface{}) {
	*h = append(*h, x.(int))
}

// Pop 从堆中移除并返回最小元素。
func (h *IntHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[0 : n-1]
	return x
}

func main() {
	h := &IntHeap{2, 1, 5}
	heap.Init(h)
	heap.Push(h, 3)
	fmt.Printf("最小元素: %d\n", (*h)[0])
	for h.Len() > 0 {
		fmt.Printf("%d ", heap.Pop(h))
	}
}
```

在这个示例中：

- `IntHeap` 是一个整数切片，表示堆中的元素。
- `Len`、`Less` 和 `Swap` 方法用于实现堆的排序和交换操作。
- `Push` 和 `Pop` 方法用于向堆中添加和移除元素。
- 在 `main` 函数中，我们创建了一个 `IntHeap` 实例，并使用 `heap.Init` 初始化堆。然后，我们使用 `heap.Push` 向堆中添加元素，并使用 `heap.Pop` 从堆中移除并返回最小元素。

运行这个程序，你会看到输出结果是按照从小到大的顺序排列的元素。

**问：如何实现大根堆呢？**

答：在Go语言中，实现大根堆（Max-Heap）可以通过使用标准库中的`container/heap`包来实现。大根堆是一种特殊的完全二叉树，其中每个节点的值都大于或等于其子节点的值。

下面是一个简单的示例，展示如何使用`container/heap`包来实现大根堆：

1. 首先，定义一个类型来表示堆中的元素。
2. 然后，实现`heap.Interface`接口的五个方法：`Len`、`Less`、`Swap`、`Push`和`Pop`。

```go
package main

import (
	"container/heap"
	"fmt"
)

// IntHeap 是一个由整数组成的最大堆。
type IntHeap []int

// Len 返回堆的长度。
func (h IntHeap) Len() int { return len(h) }

// Less 报告索引 i 的元素是否比索引 j 的元素小。
// 因为我们实现的是最大堆，所以这里返回 h[i] > h[j]。
func (h IntHeap) Less(i, j int) bool { return h[i] > h[j] }

// Swap 交换索引 i 和 j 的元素。
func (h IntHeap) Swap(i, j int) bool { h[i], h[j] = h[j], h[i] }

// Push 将元素 x 添加到堆中。
func (h *IntHeap) Push(x interface{}) {
	*h = append(*h, x.(int))
}

// Pop 从堆中移除并返回最大元素。
func (h *IntHeap) Pop() interface{} {
	old := *h
	n := len(old)
	x := old[n-1]
	*h = old[0 : n-1]
	return x
}

func main() {
	h := &IntHeap{2, 1, 5}
	heap.Init(h)
	heap.Push(h, 3)
	fmt.Printf("最大元素: %d\n", (*h)[0])
	for h.Len() > 0 {
		fmt.Printf("%d ", heap.Pop(h))
	}
}
```

在这个示例中，我们定义了一个`IntHeap`类型，并实现了`heap.Interface`接口的五个方法。然后，我们使用`heap.Init`初始化堆，使用`heap.Push`添加元素，并使用`heap.Pop`移除最大元素。

运行这个程序，你会看到输出结果是按照从大到小的顺序排列的元素，这表明我们成功地实现了一个大根堆。
