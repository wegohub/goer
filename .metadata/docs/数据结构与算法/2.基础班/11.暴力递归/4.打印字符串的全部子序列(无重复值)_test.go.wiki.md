## 问答



**问：golang中通过map实现的hashSet结构，结果是没有顺序的。怎么保证有序？
set := make(map[string]struct{})**

答：在Go语言中，`map` 类型的数据结构本身是无序的，这意味着当你遍历一个 `map` 时，无法保证遍历的顺序。如果你需要一个有序的集合（类似于Java中的 `LinkedHashSet`），可以考虑以下几种方法：

#### 方法一：使用 `map` 和 `slice` 结合

你可以使用一个 `map` 来存储元素，同时使用一个 `slice` 来记录插入顺序。

```go
package main

import (
	"fmt"
)

type OrderedSet struct {
	elements map[string]struct{}
	order    []string
}

func NewOrderedSet() *OrderedSet {
	return &OrderedSet{
		elements: make(map[string]struct{}),
		order:    []string{},
	}
}

func (s *OrderedSet) Add(value string) {
	if _, exists := s.elements[value]; !exists {
		s.elements[value] = struct{}{}
		s.order = append(s.order, value)
	}
}

func (s *OrderedSet) Values() []string {
	return s.order
}

func main() {
	set := NewOrderedSet()
	set.Add("apple")
	set.Add("banana")
	set.Add("cherry")
	set.Add("apple") // 重复元素不会被添加

	for _, value := range set.Values() {
		fmt.Println(value)
	}
}
```

#### 方法二：使用第三方库

有一些第三方库提供了有序集合的实现，例如 `go-ordered-map`。

```go
package main

import (
	"fmt"
	"github.com/wk8/go-ordered-map"
)

func main() {
	om := orderedmap.New()
	om.Set("apple", struct{}{})
	om.Set("banana", struct{}{})
	om.Set("cherry", struct{}{})

	for pair := om.Oldest(); pair != nil; pair = pair.Next() {
		fmt.Println(pair.Key)
	}
}
```

#### 方法三：自定义有序集合结构

你可以自定义一个结构体，结合 `map` 和链表来实现有序集合。

```go
package main

import (
	"fmt"
)

type Node struct {
	Value string
	Next  *Node
}

type OrderedSet struct {
	elements map[string]*Node
	head     *Node
	tail     *Node
}

func NewOrderedSet() *OrderedSet {
	return &OrderedSet{
		elements: make(map[string]*Node),
	}
}

func (s *OrderedSet) Add(value string) {
	if _, exists := s.elements[value]; !exists {
		node := &Node{Value: value}
		s.elements[value] = node
		if s.tail != nil {
			s.tail.Next = node
		}
		s.tail = node
		if s.head == nil {
			s.head = node
		}
	}
}

func (s *OrderedSet) Values() []string {
	values := []string{}
	for node := s.head; node != nil; node = node.Next {
		values = append(values, node.Value)
	}
	return values
}

func main() {
	set := NewOrderedSet()
	set.Add("apple")
	set.Add("banana")
	set.Add("cherry")
	set.Add("apple") // 重复元素不会被添加

	for _, value := range set.Values() {
		fmt.Println(value)
	}
}
```

以上方法都可以实现一个有序的集合，具体选择哪种方法取决于你的具体需求和项目环境。
