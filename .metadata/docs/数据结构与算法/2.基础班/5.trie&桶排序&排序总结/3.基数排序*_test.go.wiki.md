## 问答



**问：一个整数num怎么分别提取个位、十位、百位、千位的数字**

答：在Go语言中，你可以通过数学运算和取模操作来提取一个整数的个位、十位、百位和千位的数字。以下是一个示例代码，展示了如何实现这一点：

```go
package main

import (
	"fmt"
)

func main() {
	num := 1234

	// 提取个位数字
	ones := num % 10

	// 提取十位数字
	tens := (num / 10) % 10

	// 提取百位数字
	hundreds := (num / 100) % 10

	// 提取千位数字
	thousands := (num / 1000) % 10

	fmt.Printf("个位: %d\n", ones)
	fmt.Printf("十位: %d\n", tens)
	fmt.Printf("百位: %d\n", hundreds)
	fmt.Printf("千位: %d\n", thousands)
}
```

在这个示例中，我们使用取模运算符 `%` 和整数除法 `/` 来提取各个位上的数字。具体步骤如下：

1. **个位数字**：通过 `num % 10` 获取个位数字。
2. **十位数字**：通过 `(num / 10) % 10` 获取十位数字。
3. **百位数字**：通过 `(num / 100) % 10` 获取百位数字。
4. **千位数字**：通过 `(num / 1000) % 10` 获取千位数字。

这样，你就可以分别提取出整数 `num` 的个位、十位、百位和千位的数字。
