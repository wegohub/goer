## 问答



**问：整数n的绝对值用位运算怎么实现？**

答：在Go语言中，可以通过位运算来实现整数n的绝对值。具体实现方法如下：

```go
func Abs(n int) int {
    y := n >> (32 - 1) // 对于32位整数，右移31位
    return (n ^ y) - y  // 异或并减去y
}
```

这里解释一下这个方法的原理：

1. `y := n >> (32 - 1)`：对于32位整数，右移31位。这一步的目的是获取n的最高位（符号位）。如果n是正数或零，y将是0；如果n是负数，y将是-1（即所有位都是1）。

2. `return (n ^ y) - y`：这一步是关键。它通过异或操作和减法来计算绝对值。
   - 如果n是正数或零，y是0，那么`n ^ y`就是n本身，减去0还是n本身，所以结果是n。
   - 如果n是负数，y是-1，那么`n ^ y`会将n的所有位反转（因为-1的二进制表示是全1），然后减去-1（相当于加上1），这样就得到了n的绝对值。

这种方法利用了位运算的特性，避免了直接使用条件判断（如if语句），从而可能在某些情况下提高执行效率。不过需要注意的是，这种方法仅适用于32位整数。对于64位整数，需要相应地调整位移的位数。
