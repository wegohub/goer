**问：你能实现三数之和吗？**

答：当然可以！三数之和问题是一个经典的算法问题，通常要求在一个数组中找到所有不重复的三元组，使得它们的和为零。我们可以使用双指针法来解决这个问题。

以下是使用 Go 语言实现三数之和的代码：

```go
package main

import (
	"fmt"
	"sort"
)

func threeSum(nums []int) [][]int {
	var result [][]int
	sort.Ints(nums) // 先对数组进行排序

	for i := 0; i < len(nums)-2; i++ {
		// 避免重复的第一个数
		if i > 0 && nums[i] == nums[i-1] {
			continue
		}

		left, right := i+1, len(nums)-1
		for left < right {
			sum := nums[i] + nums[left] + nums[right]
			if sum == 0 {
				result = append(result, []int{nums[i], nums[left], nums[right]})
				left++
				right--

				// 避免重复的第二个数
				for left < right && nums[left] == nums[left-1] {
					left++
				}
				// 避免重复的第三个数
				for left < right && nums[right] == nums[right+1] {
					right--
				}
			} else if sum < 0 {
				left++
			} else {
				right--
			}
		}
	}

	return result
}

func main() {
	nums := []int{-1, 0, 1, 2, -1, -4}
	result := threeSum(nums)
	fmt.Println(result)
}
```

#### 代码解释：
1. **排序**：首先对数组进行排序，这样可以方便地使用双指针法。
2. **遍历数组**：外层循环遍历数组，`i` 是当前固定的第一个数。
3. **双指针法**：在 `i` 之后的数组中使用双指针 `left` 和 `right`，分别指向 `i+1` 和数组的末尾。
4. **避免重复**：在找到一个三元组后，移动指针时要跳过相同的数，以避免重复的三元组。
5. **返回结果**：将所有符合条件的三元组添加到结果中并返回。

#### 示例输出：
对于输入 `nums := []int{-1, 0, 1, 2, -1, -4}`，输出将是：
```
[[-1 -1 2] [-1 0 1]]
```

这个实现的时间复杂度是 `O(n^2)`，其中 `n` 是数组的长度。
