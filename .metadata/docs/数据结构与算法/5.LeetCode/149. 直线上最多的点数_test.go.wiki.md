## 问答



**问：golang求最大公倍数**

答：在Go语言中，求两个数的最大公倍数（LCM，Least Common Multiple）可以通过先求出它们的最大公约数（GCD，Greatest Common Divisor）来实现。这是因为两个数的最大公倍数和它们的最大公约数之间有一个简单的数学关系：`LCM(a, b) = |a * b| / GCD(a, b)`。

下面是一个简单的Go程序，展示了如何计算两个整数的最大公倍数：

```go
package main

import (
	"fmt"
	"math"
)

// 计算两个数的最大公约数
func gcd(a, b int) int {
	for b != 0 {
		a, b = b, a % b
	}
	return a
}

// 计算两个数的最大公倍数
func lcm(a, b int) int {
	return int(math.Abs(float64(a*b))) / gcd(a, b)
}

func main() {
	a := 15
	b := 20
	fmt.Printf("数字 %d 和 %d 的最大公倍数是 %d\n", a, b, lcm(a, b))
}
```

在这个程序中，`gcd`函数使用欧几里得算法来计算两个数的最大公约数。`lcm`函数则利用了最大公倍数和最大公约数之间的关系来计算最大公倍数。`math.Abs`用于确保结果是正数，因为最大公倍数总是正数。

运行这个程序，你会看到输出：

```
数字 15 和 20 的最大公倍数是 60
```

这表明15和20的最大公倍数是60，验证了程序的正确性。
