用golang实现这个方法**

答：在Go语言中实现这个方法，我们需要注意几个关键点：

1. Go语言中没有内置的`knows`函数，所以我们需要假设这个函数已经存在，或者我们需要自己定义这个函数。
2. Go语言的函数签名和Java有所不同，特别是在返回值和错误处理方面。

假设`knows`函数已经定义好，它接受两个整数参数并返回一个布尔值，表示第一个人是否认识第二个人。下面是这个方法的Go语言实现：

```go
package main

// 假设knows函数已经定义
// func knows(a int, b int) bool {
//     // 实现细节依赖于具体问题
// }

func findCelebrity(n int) int {
    cand := 0
    for i := 0; i < n; i++ {
        if knows(cand, i) {
            cand = i
        }
    }
    for i := 0; i < cand; i++ {
        if knows(cand, i) {
            return -1
        }
    }
    for i := 0; i < n; i++ {
        if !knows(i, cand) {
            return -1
        }
    }
    return cand
}

func main() {
    // 示例调用，假设n和knows函数的实现已经定义

}
```

在这个实现中，我们首先找到一个可能是“名人”的候选人，然后验证这个候选人是否满足“名人”的条件：即他不认识任何人，但所有人都认识他。如果不满足这些条件，则返回-1表示没有找到名人。

请注意，这个实现依赖于`knows`函数的正确实现。在实际应用中，你需要根据具体问题来定义`knows`函数。
