## 问答



**问：public static int hammingWeight2(int n) {
		n = (n & 0x55555555) + ((n >>> 1) & 0x55555555);
		n = (n & 0x33333333) + ((n >>> 2) & 0x33333333);
		n = (n & 0x0f0f0f0f) + ((n >>> 4) & 0x0f0f0f0f);
		n = (n & 0x00ff00ff) + ((n >>> 8) & 0x00ff00ff);
		n = (n & 0x0000ffff) + ((n >>> 16) & 0x0000ffff);
		return n;
	}

用golang实现**

答：在Go语言中，我们可以使用类似的方法来计算一个整数的汉明重量（即二进制表示中1的个数）。以下是使用Go语言实现的代码：

```go
package main

import "fmt"

func hammingWeight(n int) int {
    n = (n & 0x55555555) + ((n >> 1) & 0x55555555)
    n = (n & 0x33333333) + ((n >> 2) & 0x33333333)
    n = (n & 0x0f0f0f0f) + ((n >> 4) & 0x0f0f0f0f)
    n = (n & 0x00ff00ff) + ((n >> 8) & 0x00ff00ff)
    n = (n & 0x0000ffff) + ((n >> 16) & 0x0000ffff)
    return n
}

func main() {
    fmt.Println(hammingWeight(11)) // 输出: 3
}
```

这段代码与Java版本的逻辑相同，通过位操作逐步计算出整数中1的个数。需要注意的是，Go语言中的位移操作符是`>>`，而不是Java中的`>>>`。在Go中，`>>`对于无符号整数执行的是逻辑右移，对于有符号整数执行的是算术右移。由于我们在这里处理的是32位整数，且目的是计算1的个数，因此使用算术右移即可。
