Kafka

## 总结

- [kafka笔记](../../../../static/clips/pdf/kafka笔记.pdf)

- zk的使用

```
zkCli.sh -server localhost:2181
ls ls /brokers/ids/0
```

- 创建主题

```
./kafka-topics.sh --create --zookeeper 172.16.253.35:2181 --replication-factor 1 --partitions 1 --topic test

列出所有主题：
./kafka-topics.sh --list --zookeeper 172.16.253.35:2181
```

- 生产者发送消息

```
./kafka-console-producer.sh --broker-list 127.0.0.1:9092 --topic test
```

- 消费者消费消息

```
./kafka-console-consumer.sh --bootstrap-server 127.0.0.1:9092 --from-beginning --topic test
```

- 查看消费者组信息

```
./kafka-consumer-groups.sh --bootstrap-server 127.0.0.1:9092 --describe --group testGroup1
```
